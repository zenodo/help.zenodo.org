    Element 6: Table for Expected Data Type and Established Repository or Example

    Question

    In the table below, please list [100 words maximum]:

    1. Key types of scientific data anticipated to be generated during the project, including the species and modality, if known (e.g., “human genomic data,” “rat functional magnetic resonance imaging data”). NIH recognizes that not all data types expected to be generated in the study will meet the definition of scientific data or can be anticipated in advance. If a data type does not appear on the list, it does not imply that that data type will not be shared if it is generated in the study.
    2. The repository or an example of a repository where the scientific data may be managed and shared, if the scientific data is known at time of application. NIH expects the use of established repositories for preserving and sharing scientific data when they are available.
    Expected Data Type Established Repository or Example
    - -

    Guidance for Response

    Since expected, example responses for data type are outlined above, we will concentrate on guidance for the repository portion of the table. List Zenodo.org as the repository where scientific data arising from your project will be managed and shared. Note: Zenodo may be employed in combination with deposits to other repositories (e.g., in a case where subsets of data needing access controls might be deposited to an NIH-sponsored repository, while other subsets that are safe to make publicly available may be deposited in Zenodo).

    Zenodo note: Zenodo's features meet the primary Desirable Characteristics for All Data Repositories outlined by the NIH. These include issuing a unique persistent identifier (DOI), provenance, and long-term sustainability.

    These qualities of Zenodo keep it aligned with the FAIR principles:

    Principle Description
    Findable Each deposit is issued a DOI, making it permanently findable, identifiable, and retrievable via the internet
    Accessible Zenodo's emphasis on Open Access deposits helps to ensure that deposited datasets are accessible for the foreseeable future
    Interoperable The use of widely adopted code and API standards make Zenodo records highly interoperable
    Reusable Zenodo offers the user a wide selection of licenses for their deposits, ensuring that they can specify the conditions of data re-use
