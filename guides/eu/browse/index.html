    1. Docs

    Browse collections

    The EU Open Research Repository allows you to browse collections of content of the repository. The collections are managed automatically based on the metadata in the records. Each section below details how the specific collection is being managed.

    This guide covers:

    • Browsing overview
    • Browse by funding programme
    • Browse by subject
    • Browse by projects
    • Search in a collection

    Browsing overview

    1

    Click Browse in the menu in EU Open Research Repository (see how in navigation). The browse page has three sections

    • Funding programmes - Allows you to browse by specific funding programmes such has Horizon Europe, Horizon 2020, Euratom, ERC and MCSA.
    • Subjects - Allows you to browse by specific subjects such as Social Sciences, Natural sciences etc.
    • Projects - Allows you to browse and search EU project communities.

    2

    Alternatively, the high-level collections are also displayed on the frontpage (see navigation) of the EU Open Research Repository.

    Browse by funding programme

    The funding programme collections are managed automatically based on the grant(s) linked in the record. Note that records with custom grants will not be browsable in the funding programme collections.

    1

    Click any of the collections under Funding programme (see above) - for instance Horizon Europe.

    2

    Next, you'll be able to browse and search the specific collection like a normal Zenodo search result. See how to search in a collection below.

    Browse by subject

    The subject collections are managed automatically based on the subjects specified in the record as well as the associated grant(s) linked in the record (except for custom grants). Each grant has an associated set of subjects set by CORDIS in our grant database.

    1

    Click any of the collections under Subjects - for instance Biological sciences.

    2

    Next, you'll be able to browse and search the specific collection like a normal Zenodo search result. See how to search in a collection below.

    3

    You can navigate up the subject hierarchy (i.e. in case of biological sciences to go to natural sciences) using the collection breadcrumb navigation.

    Browse by projects

    1

    Click the See all link next to the title.

    2

    Next, you'll be able search through EU Project Communities (see search field in screenshot below). You can also use the facets to filter by:

    • Funders - for projects that are co-funded by other funders.
    • Organizations - which are partners on the projects.

    Search in a collection

    1

    You can search in any of the collections using the normal header search field (see navigation). The search field is contextualized, so you can choose to search in either:

    • the collection
    • the EU Open Research Repository
    • all of Zenodo.

    Just use the arrow up and down to select where you want to search. By default, you search the collection you are viewing.
